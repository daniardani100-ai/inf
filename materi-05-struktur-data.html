Struktur Data Dasar (Array, Stack, Queue) & Algoritma

Pahami bagaimana komputer mengatur dan mengelola data dalam memori: eksplorasi indeks Array, mekanisme tumpukan Stack (LIFO), jalur antrian Queue (FIFO), serta algoritma pencarian (Linear & Binary Search) dan pengurutan (Sorting).

📦 Struktur Data Array (Larik)

Array adalah struktur data paling mendasar yang menyimpan kumpulan elemen bertipe sama di dalam blok memori yang bersebelahan (contiguous memory allocation). Setiap elemen dapat diakses secara instan melalui nomor posisi yang disebut Indeks (Index).

Konvensi Zero-Indexed: Di hampir seluruh bahasa pemrograman modern (Python, C++, Java, JavaScript), indeks Array selalu dimulai dari angka 0, bukan 1. Jika ukuran array adalah N, maka indeks terakhirnya adalah N - 1.

✅ Kelebihan Array

Akses elemen sangat cepat (kompleksitas waktu O(1)) karena komputer cukup menghitung offset memori secara langsung berdasarkan indeks.

❌ Keterbatasan Array

Ukuran bersifat statis (tetap). Menambah atau menyisipkan elemen baru di tengah memerlukan pergeseran posisi seluruh elemen lainnya.

📚 Struktur Data Stack (Tumpukan - LIFO)

Stack adalah struktur data linear yang bekerja dengan prinsip LIFO (Last In, First Out)—artinya elemen yang terakhir dimasukkan akan menjadi elemen pertama yang dikeluarkan. Bayangkan seperti tumpukan piring di kantin atau tumpukan baki makanan.

Prinsip LIFO: Penambahan dan penghapusan data hanya dapat dilakukan pada satu ujung yang sama, yaitu ujung atas (TOP).

3 Operasi Fundamental Stack:

📥 PUSH

Menambahkan / memasukkan elemen baru ke posisi paling atas (TOP) tumpukan.

📤 POP

Mengambil dan menghapus elemen yang berada di posisi paling atas (TOP).

👀 PEEK / TOP

Melihat nilai elemen paling atas tanpa menghapusnya dari tumpukan.

Penerapan Nyata Stack di Dunia Nyata:

• Fitur Undo / Redo (Ctrl + Z) di aplikasi Word atau Photo Editor.
• Tombol Back (Kembali) pada browser saat menjelajah situs web.
• Manajemen pemanggilan fungsi dalam memori sistem (Call Stack Execution).

🚶‍♂️ Struktur Data Queue (Antrian - FIFO)

Queue adalah struktur data linear yang menerapkan prinsip FIFO (First In, First Out)—elemen yang pertama masuk akan menjadi yang pertama dilayani/keluar. Persis seperti antrian pembeli tiket di bioskop atau loket kasir.

Prinsip FIFO: Elemen masuk melalui pintu belakang (REAR / BACK) dan keluar melalui pintu depan (FRONT).

2 Operasi Fundamental Queue:

➡️ ENQUEUE

Memasukkan elemen baru ke bagian belakang (REAR/TAIL) antrian.

⬅️ DEQUEUE

Mengeluarkan dan menghapus elemen dari bagian depan (FRONT/HEAD) antrian.

Penerapan Nyata Queue di Sistem Komputer:

• Print Spooler: Dokumen yang pertama dikirim ke printer akan dicetak lebih dahulu.
• CPU Scheduling: Antrian proses aplikasi yang menunggu giliran dieksekusi prosesor.
• Buffer Streaming Video: Paket data video dimainkan berurutan sesuai kedatangannya.

🔍 Algoritma Pencarian & Pengurutan Dasar

Setelah data disimpan dalam struktur data, langkah berikutnya adalah memprosesnya menggunakan algoritma standar:

1. Algoritma Pencarian (Searching)

🎯 Linear Search (Pencarian Berurutan)

Memeriksa setiap elemen satu per satu dari awal sampai akhir. Cocok untuk data acak (tidak terurut), tetapi lambat jika data sangat besar.

⚡ Binary Search (Pencarian Biner)

Membagi dua ruang pencarian secara berulang (Divide and Conquer). Syarat Mutlak: Data harus sudah terurut terlebih dahulu!

2. Algoritma Pengurutan (Bubble Sort)

Prinsip Bubble Sort: Membandingkan dua elemen yang bersebelahan dan menukarnya (swap) jika posisinya salah. Elemen terbesar akan "mengapung" ke posisi akhir seperti gelembung udara pada setiap putaran (*pass*).
