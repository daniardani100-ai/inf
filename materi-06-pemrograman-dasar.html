Algoritma & Pemrograman Dasar (Pseudocode / Kode)

Pelajari cara menyusun logika komputasi formal: merumuskan langkah solusi dengan notasi terstandar Pseudocode, memahami deklarasi variabel dan tipe data, merancang alur keputusan kondisional (IF-ELSE), serta mengulang perintah secara efisien menggunakan perulangan (Loops).

📝 Notasi Algoritma: Pseudocode vs Flowchart vs Kode Nyata

Sebelum menulis kode program di komputer (Python, C++, atau JavaScript), programmer profesional terlebih dahulu merumuskan alur logikanya menggunakan Pseudocode (kode semu yang mudah dipahami manusia namun terstruktur seperti komputer).

3 Bagian Standar Struktur Algoritma Pseudocode:
1. Judul (Header): Nama program dan deskripsi singkat tujuannya.
2. Kamus (Deklarasi): Tempat mendefinisikan nama variabel dan tipe datanya.
3. Deskripsi (Algoritma Inti): Rangkaian instruksi eksekusi (Input ➔ Proses ➔ Output).

Tipe Data Fundamental dalam Pemrograman

🔢 Integer (Bilangan Bulat)

Menyimpan angka tanpa koma desimal (contoh: 10, -5, 2026).

🌊 Float / Real (Desimal)

Menyimpan angka berkoma / pecahan (contoh: 3.14, 87.5, 0.01).

🔤 String & Char (Teks)

Karakter atau untaian kalimat yang diapit tanda petik (contoh: "Informatika", 'A').

⚖️ Boolean (Logika)

Hanya memiliki dua kemungkinan nilai kebenaran: TRUE (Benar) atau FALSE (Salah).

Contoh Kode Pseudocode: Menghitung Luas Persegi Panjang

PSEUDOCODE: HitungLuasPersegiPanjang Notasi Standar
PROGRAM HitungLuasPersegiPanjang // Menghitung luas persegi panjang dari input panjang dan lebar DEKLARASI: panjang, lebar, luas : FLOAT ALGORITMA: INPUT(panjang) INPUT(lebar) luas <- panjang * lebar OUTPUT("Luas Persegi Panjang adalah: ", luas) END PROGRAM

🔀 Struktur Kontrol Percabangan (Kondisional / Branching)

Komputer dapat mengambil keputusan yang berbeda tergantung pada apakah suatu kondisi boolean bernilai TRUE atau FALSE.

1. Percabangan Tunggal (IF)

Instruksi hanya dijalankan jika kondisi terpenuhi; jika tidak, instruksi diabaikan dan program lanjut ke baris berikutnya.

2. Percabangan Ganda (IF - ELSE)

Menyediakan dua jalur: jalur pertama jika kondisi TRUE, dan jalur alternatif (ELSE) jika kondisi FALSE.

Contoh Pseudocode: Penentuan Kelulusan Nilai Siswa

PSEUDOCODE: CekKelulusanSiswa Logika IF-ELSE
PROGRAM CekKelulusan DEKLARASI: nilaiAkhir : INTEGER ALGORITMA: INPUT(nilaiAkhir) IF nilaiAkhir >= 75 THEN OUTPUT("Selamat, Anda TUNTAS (Kompeten)!") ELSE OUTPUT("Perlu Mengikuti Remedial / Bimbingan.") END IF

🔁 Struktur Kontrol Perulangan (Iteration / Loops)

Daripada menulis 1.000 baris kode yang sama berulang-ulang, kita menggunakan konstruksi perulangan untuk mengeksekusi blok instruksi berkali-kali secara otomatis.

1. Perulangan FOR (Counted Loop)

Digunakan saat jumlah iterasi perulangan sudah diketahui secara pasti sejak awal (misal mencetak angka 1 sampai 10).

2. Perulangan WHILE (Uncounted Loop)

Digunakan saat jumlah perulangan belum pasti dan terus berjalan selama kondisi logika masih bernilai TRUE.

Contoh Pseudocode: Mencetak Angka 1 hingga 5 dengan FOR Loop

PSEUDOCODE: CetakDeretAngka Logika FOR Loop
PROGRAM CetakDeret DEKLARASI: i : INTEGER ALGORITMA: FOR i <- 1 TO 5 DO OUTPUT("Nilai i ke: ", i) END FOR
