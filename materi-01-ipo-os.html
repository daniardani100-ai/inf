Simulasi Input-Process-Output (I-P-O) & Sistem Operasi

Pelajari bagaimana komputer bekerja dari tingkat fisik hingga logika instruksi: memahami arsitektur Von Neumann, siklus mesin (Fetch-Decode-Execute), peran vital OS sebagai jembatan hardware-user, serta visualisasi langsung alur aliran bit data.

🏛️ Arsitektur Komputer Von Neumann & Model I-P-O

Hampir seluruh perangkat digital modern saat ini—mulai dari smartphone, laptop, hingga server superkomputer—menggunakan prinsip arsitektur yang dirancang oleh matematikawan John von Neumann pada tahun 1945.

Prinsip Inti Von Neumann (Stored-Program Concept): Data dan instruksi program disimpan bersama di dalam satu memori utama (RAM) sebelum dieksekusi secara sekuensial oleh unit pemroses pusat (CPU).

3 Komponen Utama Pemroses Data

🎛️ Control Unit (CU)

Bertindak sebagai "polisi lalu lintas" CPU. Mengambil instruksi dari memori, menguraikan maknanya (decode), dan mengatur transfer sinyal ke seluruh komponen komputer.

➕ ALU (Arithmetic Logic Unit)

Pabrik kalkulasi sesungguhnya. Melakukan operasi matematika (+, -, *, /) dan logika komparasi (AND, OR, NOT, >, <, ==).

⚡ Registers

Memori internal CPU berkecepatan ultra-tinggi namun berkapasitas sangat kecil untuk menyimpan variabel sementara saat komputasi berlangsung.

Siklus Mesin (Machine Cycle): Cara CPU Menjalankan 1 Perintah

1. Fetch (Jemput): CU mengambil kode instruksi biner berikutnya dari RAM berdasarkan penunjuk Program Counter (PC).
2. Decode (Terjemahkan): CU menerjemahkan opcode instruksi untuk mengetahui operasi apa yang diminta.
3. Execute (Eksekusi): ALU menjalankan instruksi tersebut (misal menjumlahkan dua register).
4. Store (Simpan Balik): Hasil akhir ditulis kembali ke register atau alamat RAM yang dituju.

⚙️ Peran Vital Sistem Operasi (Operating System)

Perangkat keras (hardware) komputer hanyalah sekumpulan sirkuit silikon dan listrik mati jika tidak ada Sistem Operasi (OS). OS adalah perangkat lunak sistem fundamental yang mengelola seluruh sumber daya perangkat keras dan menyediakan lingkungan kerja bagi aplikasi dan pengguna.

📊 1. Manajemen Memori (RAM)

Mengalokasikan blok alamat RAM ketika sebuah aplikasi dibuka dan membersihkannya (deallocation) saat ditutup agar aplikasi tidak saling menimpa memori (Crash / Blue Screen).

⏳ 2. Manajemen Proses & CPU Scheduling

Mengatur giliran jutaan instruksi aplikasi menggunakan algoritma penjadwalan (Round Robin, FCFS) sehingga komputer terasa bisa menjalankan banyak aplikasi bersamaan (Multitasking).

📁 3. Manajemen File System

Mengatur struktur penyimpanan fisik pada SSD/HDD menjadi struktur hierarki folder, izin akses (read/write/execute), dan kompresi data (NTFS, EXT4, APFS).

🔌 4. Device Drivers & I/O Control

Menjadi penerjemah antara kode perangkat lunak generik dengan spesifikasi teknis hardware unik (Printer, VGA, WebCam, Keyboard).

🔍 Studi Kasus: Menelusuri Jejak Data Saat Menekan Tombol Keyboard

Pernahkah kamu berpikir apa yang terjadi di dalam mesin komputer saat kamu menekan tombol huruf 'A' di keyboard hingga huruf itu muncul di layar monitor? Berikut runutan mikro-detiknya:

1️⃣
Pemicu Fisik (Keyboard Switch):

Kamu menekan tombol 'A'. Saklar mekanik terhubung dan mikrokontroler keyboard menghasilkan sinyal Scan Code biner 00011110.

2️⃣
Sinyal Interupsi Perangkat (Interrupt Request - IRQ):

Driver USB mengirim sinyal interupsi ke CPU: "Hentikan sejenak pekerjaanmu, ada input keyboard baru!" CPU langsung merespons dan menyimpan kode ASCII (65 / 0x41) ke buffer RAM.

3️⃣
Pemrosesan Kernel OS & Aplikasi:

Sistem Operasi menerima event KeyDown, mengecek aplikasi mana yang sedang aktif (misal Microsoft Word atau Notepad), lalu meneruskan karakter 'A' ke memori aplikasi tersebut.

4️⃣
Rendering Grafis (Output Display):

Aplikasi meminta OS dan driver GPU merender glif bitmap huruf 'A'. Piksel-piksel pada panel monitor dinyalakan sesuai koordinat kursor. Seluruh proses ini hanya memakan waktu ± 5-15 milidetik!
